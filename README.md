# Height Consulting Premium Site

Premium single-page website for Height Consulting.

## Structure

- `index.html` — full site (all CSS/JS inline)
- `*.mp4` — cinematic AI-generated video backgrounds
- `netlify.toml` — Netlify config (publish root, no build)

## Deploy

Drag this folder into Netlify, or connect this repo to a Netlify site with:
- Build command: (none)
- Publish directory: `.`

## Tech

- Vanilla HTML/CSS/JS
- GSAP + ScrollTrigger (scroll animations)
- Lenis (smooth scroll)
- Canvas particle network on hero
- AI videos generated via kie.ai Runway API
